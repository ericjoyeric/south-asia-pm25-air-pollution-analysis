South Asia PM2.5 Air Pollution Analysis using Power BI

Project Overview

This project analyzes PM2.5 air pollution patterns across five South Asian countries using Power BI. The dashboard explores pollution levels across cities, 
countries, and time periods to identify geographic differences and trends in air quality.

The analysis uses daily city-level PM2.5 estimates from October 2018 to August 2026 and includes population-wise exploration to investigate the relationship 
between city population and pollution levels.

Problem Statement

Air pollution is a major environmental and public health concern. Understanding how PM2.5 pollution varies across locations and over time can help 
identify areas with higher recorded pollution levels and support better environmental monitoring.

This project uses interactive data visualization to explore pollution patterns across South Asia.

Objectives

- Analyze average, maximum, and minimum PM2.5 values.
- Compare pollution levels across five South Asian countries.
- Identify cities with higher average PM2.5 values.
- Examine daily, monthly, and yearly pollution trends.
- Explore the distribution of PM2.5 values across selected concentration ranges.
- Investigate the relationship between city population and average PM2.5 levels.
- Build an interactive Power BI dashboard for exploring the results.

Dataset

-Source: World Bank Data Catalog
-Dataset: Daily City-Level Air Pollution PM2.5 Estimates, 2018–2026
-Geographic coverage: South Asia
-Countries analyzed: Bangladesh, Bhutan, India, Nepal, and Sri Lanka
-Time period: October 2018 – August 2026
-Scale: Approximately 11 million observations across around 4,000 cities

Dataset link:
https://datacatalog.worldbank.org/search/dataset/0067162/daily-city-level-air-pollution-pm2-5-estimates-2018-2026

The dataset contains location, date, population, and PM2.5-related fields used for geographic and time-based analysis.
